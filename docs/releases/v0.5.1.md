Fixes for unusual PDFs and pasted text, and PaperKnife is now also on Mac and Android.

## What's fixed

- **Pages whose font stores its character map in an unusual way.** A PDF can compress a font's
  character map in a form that asks for a preset dictionary, which a PDF can't provide.
  PaperKnife failed to read such a page, so it couldn't show it at all. It now treats that data
  as damaged, as it does other damaged data: the page opens, and its text can be edited.
- **A crafted PDF could make PaperKnife stop responding.** An image stored in a page's drawing
  instructions with an impossibly large size made PaperKnife read the same image again and
  again, forever. It now reads past such an image correctly.
- **Pasting unusual characters could close PaperKnife.** Text holding the character U+FFFE or a
  broken (unpaired) surrogate, which pasted text can, closed PaperKnife when you applied it, and
  unsaved changes were lost. PaperKnife now refuses it with "This text has characters that aren't
  valid Unicode: U+FFFE".

The Mac and Android ports found all three: every PaperKnife app runs the same 128 conformance
tests, which compare everything the engine observes with what PaperKnife for Windows observes,
and these cases came up while porting.

## PaperKnife for Mac and Android

[PaperKnife for Mac](https://github.com/shivam098/paperknife-macos/releases/latest) and
[PaperKnife for Android](https://github.com/shivam098/paperknife-android/releases/latest) are
out, also as version 0.5.1. They are native apps with the same editing engine, ported line by
line from this one, so they edit the same PDFs the same way, including everything fixed since
version 0.1.0: whole lines selected in PDFs that draw every letter on its own, edits in the
page's own drawing instructions, and new letters in LaTeX PDFs.

## Which file do I need?

| File | Choose it if |
|---|---|
| `PaperKnife-0.5.1-setup.exe` | **Most people.** One installer for every 64-bit PC (Intel, AMD or Arm). It installs for your account only, without administrator rights, and adds PaperKnife to the Start menu and to **Open with** for PDFs. Installing it over an earlier version upgrades it in place. |
| `PaperKnife-0.5.1-x64-portable.zip` | You'd rather not install anything, on an Intel or AMD PC: unzip and run `PaperKnife.exe`. |
| `PaperKnife-0.5.1-arm64-portable.zip` | The same, on an Arm PC (for example Snapdragon). |
| `SHA256SUMS.txt` | Checksums of the files above. |

PaperKnife needs Windows 10 (version 1809) or later, or Windows 11. Nothing else needs to be
installed.

**This release isn't code-signed yet.** If Windows shows "Windows protected your PC", select
**More info**, then **Run anyway**. If Smart App Control is turned on, it may block PaperKnife
until releases are signed. To uninstall PaperKnife, use *Settings > Apps*.

## Known limits

PaperKnife refuses an edit rather than damage your document. In this version it can't:

- add characters that the PDF's font doesn't contain, except in LaTeX's Computer Modern, Latin
  Modern and CM-Super fonts. Even there, which characters it can add depends on how LaTeX
  encoded the font: LaTeX's default encoding has no accented letters; in PDFs made before
  mid-2021 it can add only the font's own set (CM-Super's has no accented letters the document
  doesn't use); and symbols LaTeX takes from a separate font, such as © in body text, usually
  can't be added. In encrypted LaTeX PDFs it can only delete whole lines, and in PDFs made with
  XeLaTeX or LuaLaTeX, which embed Latin Modern in another format, it can't add letters;
- keep centered text centered: the edited text starts where the old text started;
- edit some pages of encrypted PDFs: they are still edited by rewriting the whole page, which is
  refused when the page has gradients, letter spacing, print colors, small images or fonts stored
  as drawings;
- edit a line as one piece when the PDF splits it across fonts, for example the "fi" in
  "Confirmed" in PDFs saved from Chrome; each piece can be edited on its own;
- edit scripts that need text shaping (such as Hindi or Arabic), add line breaks or move text
  that follows on other lines, or edit scanned pages.

Each edit adds the page's drawing instructions to the file again: usually a few kilobytes, more on
pages with a lot of graphics. An edit that needs a copy of a font also adds the font: about 100 KB
for Latin Modern, 140 KB for CM-Super. See the
[roadmap](https://github.com/shivam098/paperknife-windows/blob/main/docs/ROADMAP.md) for what's
next.

This is an early preview: keep a backup of any document you can't afford to lose, and please
[report problems](https://github.com/shivam098/paperknife-windows/issues).
