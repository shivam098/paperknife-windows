Edit PDFs made with LaTeX, such as résumés and papers.

## What's new

- **Spaces in LaTeX PDFs.** LaTeX's fonts have no space character: LaTeX leaves a gap between
  words instead. PaperKnife used to refuse any edit with a space in these PDFs. It now leaves the
  same kind of gap, so you can change whole lines, add words and keep the text searchable.
- **New letters in LaTeX PDFs.** LaTeX embeds only the letters a document uses, so typing a new
  name or a different digit used to fail with "the font doesn't contain…". PaperKnife now ships
  LaTeX's Computer Modern fonts (from the American Mathematical Society, under the SIL Open Font
  License). When a PDF has only part of one of them, PaperKnife draws your text with a complete
  copy of the same font, after checking that every letter already in the PDF is identical in it,
  and tells you when it does. The new letters match the rest of the text exactly. The PDF's own
  font isn't changed, so the rest of the document stays exactly as it was; the file grows by
  about 30 KB per font.
- **Edited text keeps its spacing.** Text you don't change within an edited line keeps its
  kerning, ligatures and the gaps between its words, so only what you changed looks different,
  also in LaTeX PDFs without a text map.
- **Clearer messages.** When a character really is missing, the message names invisible ones,
  for example "doesn't contain: space".
- **Still verified.** Every edit is checked as before: the rest of the page must look exactly the
  same and the rest of the line must sit exactly where it was moved, and new letters must really
  be drawn with the copy of the font. If not, the edit is cancelled and your document stays as
  it was.

## Which file do I need?

| File | Choose it if |
|---|---|
| `PaperKnife-0.3.0-setup.exe` | **Most people.** One installer for every 64-bit PC (Intel, AMD or Arm). It installs for your account only, without administrator rights, and adds PaperKnife to the Start menu and to **Open with** for PDFs. Installing it over an earlier version upgrades it in place. |
| `PaperKnife-0.3.0-x64-portable.zip` | You'd rather not install anything, on an Intel or AMD PC: unzip and run `PaperKnife.exe`. |
| `PaperKnife-0.3.0-arm64-portable.zip` | The same, on an Arm PC (for example Snapdragon). |
| `SHA256SUMS.txt` | Checksums of the files above. |

PaperKnife needs Windows 10 (version 1809) or later, or Windows 11. Nothing else needs to be
installed.

**This release isn't code-signed yet.** If Windows shows "Windows protected your PC", select
**More info**, then **Run anyway**. If Smart App Control is turned on, it may block PaperKnife
until releases are signed. To uninstall PaperKnife, use *Settings > Apps*.

## Known limits

PaperKnife refuses an edit rather than damage your document. In this version it can't:

- add characters that the PDF's font doesn't contain, except in LaTeX's Computer Modern fonts
  (LaTeX documents set in Latin Modern or with `\usepackage[T1]{fontenc}` use other fonts, which
  PaperKnife can't complete yet);
- keep centered text centered: the edited text starts where the old text started;
- edit some pages of encrypted PDFs: they are still edited by rewriting the whole page, which is
  refused when the page has gradients, letter spacing, print colors, small images or fonts stored
  as drawings;
- edit a line as one piece when the PDF splits it across fonts, for example the "fi" in
  "Confirmed" in PDFs saved from Chrome; each piece can be edited on its own;
- delete a whole line, edit scripts that need text shaping (such as Hindi or Arabic), add line
  breaks or move text that follows on other lines, or edit scanned pages.

Each edit adds the page's drawing instructions to the file again: usually a few kilobytes, more on
pages with a lot of graphics. See the
[roadmap](https://github.com/shivam098/paperknife-windows/blob/main/docs/ROADMAP.md) for what's
next.

This is an early preview: keep a backup of any document you can't afford to lose, and please
[report problems](https://github.com/shivam098/paperknife-windows/issues).
