Delete whole lines of text.

## What's new

- **Delete text.** Select a line and choose **Delete text**, or clear the text and press Enter.
  PaperKnife used to refuse with "Deleting a whole line of text isn't supported yet." It removes
  just that text; everything else on the page stays exactly where it was. **Undo** brings it
  back.
- **Works in more fonts than editing does.** Deleting doesn't need to write any letters, so it
  also works for text PaperKnife can't edit yet, for example Chinese or Japanese text in some
  fonts.
- **Still verified.** After deleting, PaperKnife checks that the page looks exactly as it did
  with that text hidden, and that every other piece of text is still there, unchanged, including
  invisible text such as the searchable layer of a scanned page. If not, nothing is deleted and
  your document stays as it was.
- **Safer edits in encrypted PDFs.** When PaperKnife has to rewrite a whole page (for example in
  password-protected PDFs), it now also refuses edits that would change the spacing of invisible
  text, such as the searchable layer of a scanned page. Before, that spacing could change
  unnoticed.

## Which file do I need?

| File | Choose it if |
|---|---|
| `PaperKnife-0.4.0-setup.exe` | **Most people.** One installer for every 64-bit PC (Intel, AMD or Arm). It installs for your account only, without administrator rights, and adds PaperKnife to the Start menu and to **Open with** for PDFs. Installing it over an earlier version upgrades it in place. |
| `PaperKnife-0.4.0-x64-portable.zip` | You'd rather not install anything, on an Intel or AMD PC: unzip and run `PaperKnife.exe`. |
| `PaperKnife-0.4.0-arm64-portable.zip` | The same, on an Arm PC (for example Snapdragon). |
| `SHA256SUMS.txt` | Checksums of the files above. |

PaperKnife needs Windows 10 (version 1809) or later, or Windows 11. Nothing else needs to be
installed.

**This release isn't code-signed yet.** If Windows shows "Windows protected your PC", select
**More info**, then **Run anyway**. If Smart App Control is turned on, it may block PaperKnife
until releases are signed. To uninstall PaperKnife, use *Settings > Apps*.

## Known limits

PaperKnife refuses an edit rather than damage your document. In this version it can't:

- add characters that the PDF's font doesn't contain, except in LaTeX's Computer Modern fonts
  (LaTeX documents set in Latin Modern or with `\usepackage[T1]{fontenc}` use other fonts, which
  PaperKnife can't complete yet);
- keep centered text centered: the edited text starts where the old text started;
- edit some pages of encrypted PDFs: they are still edited by rewriting the whole page, which is
  refused when the page has gradients, letter spacing, print colors, small images or fonts stored
  as drawings;
- edit a line as one piece when the PDF splits it across fonts, for example the "fi" in
  "Confirmed" in PDFs saved from Chrome; each piece can be edited on its own;
- edit scripts that need text shaping (such as Hindi or Arabic), add line breaks or move text
  that follows on other lines, or edit scanned pages.

Each edit adds the page's drawing instructions to the file again: usually a few kilobytes, more on
pages with a lot of graphics. See the
[roadmap](https://github.com/shivam098/paperknife-windows/blob/main/docs/ROADMAP.md) for what's
next.

This is an early preview: keep a backup of any document you can't afford to lose, and please
[report problems](https://github.com/shivam098/paperknife-windows/issues).
