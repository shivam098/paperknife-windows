Edit whole lines in PDFs that draw text one letter at a time.

## What's new

- **Whole lines, even in PDFs that draw text letter by letter.** Some PDFs, for example those
  made from web pages with wkhtmltopdf, draw every character or word as a separate piece of
  text. Clicking such text used to select a single letter. PaperKnife now selects the whole line
  or table cell, and *Text on this page* lists lines instead of letters.
- **Only what you change is rewritten.** When you edit such a line, PaperKnife rewrites just the
  characters you changed and moves the rest of the line to fit. You can also delete part of a
  line.
- **Still verified.** Every edit is checked as before: the rest of the page must look exactly
  the same, and the rest of the line must sit exactly where it was moved, without running off
  the page or being cut off. If not, the edit is cancelled and your document stays as it was.

## Which file do I need?

| File | Choose it if |
|---|---|
| `PaperKnife-0.1.1-setup.exe` | **Most people.** One installer for every 64-bit PC (Intel, AMD or Arm). It installs for your account only, without administrator rights, and adds PaperKnife to the Start menu and to **Open with** for PDFs. Installing it over 0.1.0 upgrades it in place. |
| `PaperKnife-0.1.1-x64-portable.zip` | You'd rather not install anything, on an Intel or AMD PC: unzip and run `PaperKnife.exe`. |
| `PaperKnife-0.1.1-arm64-portable.zip` | The same, on an Arm PC (for example Snapdragon). |
| `SHA256SUMS.txt` | Checksums of the files above. |

PaperKnife needs Windows 10 (version 1809) or later, or Windows 11. Nothing else needs to be
installed.

**This release isn't code-signed yet.** If Windows shows "Windows protected your PC", select
**More info**, then **Run anyway**. If Smart App Control is turned on, it may block PaperKnife
until releases are signed. To uninstall PaperKnife, use *Settings > Apps*.

## Known limits

PaperKnife refuses an edit rather than damage your document. In this version it can't add
characters that the PDF's font doesn't contain (PDFs often embed only the letters they already
use), delete a whole line, edit scripts that need text shaping (such as Hindi or Arabic), add
line breaks, edit scanned pages, or edit pages that PDFium can't rewrite without changing how
they look (for example pages with gradients, letter spacing, print colors or small embedded
images). See the
[roadmap](https://github.com/shivam098/paperknife-windows/blob/main/docs/ROADMAP.md) for what's
next.

This is an early preview: keep a backup of any document you can't afford to lose, and please
[report problems](https://github.com/shivam098/paperknife-windows/issues).
