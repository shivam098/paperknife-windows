The first preview of PaperKnife for Windows: a free, open-source PDF editor that works entirely
on your PC. No uploads, no account, no telemetry.

## Which file do I need?

| File | Choose it if |
|---|---|
| `PaperKnife-0.1.0-setup.exe` | **Most people.** One installer for every 64-bit PC (Intel, AMD or Arm). It installs for your account only, without administrator rights, and adds PaperKnife to the Start menu and to **Open with** for PDFs. |
| `PaperKnife-0.1.0-x64-portable.zip` | You'd rather not install anything, on an Intel or AMD PC: unzip and run `PaperKnife.exe`. |
| `PaperKnife-0.1.0-arm64-portable.zip` | The same, on an Arm PC (for example Snapdragon). |
| `SHA256SUMS.txt` | Checksums of the files above. |

PaperKnife needs Windows 10 (version 1809) or later, or Windows 11. Nothing else needs to be
installed.

**This release isn't code-signed yet.** If Windows shows "Windows protected your PC", select
**More info**, then **Run anyway**. If Smart App Control is turned on, it may block PaperKnife
until releases are signed. To uninstall PaperKnife, use *Settings > Apps*.

## What you can do

- Open PDFs, including password-protected ones; browse pages and zoom.
- **Edit existing text in place**, keeping its font, size, position and color. Click a line, or
  pick it from *Text on this page*, change it and press Enter.
- **Every edit is verified.** PaperKnife applies the change to a copy, saves and reopens it, and
  compares the rest of the page pixel by pixel. If anything else would change, or the font can't
  draw a character you typed, the edit is cancelled and your document stays as it was.
- Undo and redo, rotate and delete pages, add pages from another PDF.
- Save as a new file. An existing file is replaced in one step and is never left half-written.

## Known limits

PaperKnife refuses an edit rather than damage your document. In this version it can't add
characters that the PDF's font doesn't contain, edit scripts that need text shaping (such as
Hindi or Arabic), add line breaks, edit scanned pages, or edit pages that PDFium can't rewrite
without changing how they look (for example pages with gradients, letter spacing, print colors
or small embedded images). See the
[roadmap](https://github.com/shivam098/paperknife-windows/blob/main/docs/ROADMAP.md) for what's
next.

This is an early preview: keep a backup of any document you can't afford to lose, and please
[report problems](https://github.com/shivam098/paperknife-windows/issues).
