Type new letters in more LaTeX PDFs.

## What's new

- **New letters in Latin Modern and CM-Super.** PDFs made with LaTeX contain only the letters
  the document uses. PaperKnife already drew new letters in LaTeX's classic Computer Modern
  fonts; now it also does in the two other fonts pdfLaTeX documents commonly use: Latin Modern
  (`\usepackage{lmodern}`) and CM-Super (`\usepackage[T1]{fontenc}`). It adds a complete copy of
  the same font for your text, after checking that every letter already in the PDF is identical
  in it; the rest of the document keeps the PDF's own font.
- **Accented and Central European letters.** In PDFs made since mid-2021 with
  `\usepackage[T1]{fontenc}`, you can now type the letters of that encoding, such as é, ü, ł, Ă,
  Æ and « », also where the font's own layout puts a different letter at that position.
- **New letters are spaced correctly.** A new letter no longer takes the width LaTeX gave a
  different character at the same position, or no width at all when the PDF shares its font
  with a symbol font.
- **No wrong symbols in other LaTeX fonts.** In LaTeX PDFs set in fonts PaperKnife doesn't
  have, such as Times, typing a character the PDF never uses could draw another symbol in its
  place, for example an en dash for ±. PaperKnife now refuses such a character instead. In
  encrypted LaTeX PDFs, where it can't check this, it now only deletes whole lines.
- **Fewer refused edits in LaTeX PDFs.** Many LaTeX PDFs draw a whole page as one block of text.
  Editing a line there could shift text elsewhere on the page by a tiny fraction of a point,
  which PaperKnife's check caught, so the edit was refused with "This edit would also change …
  pixels elsewhere on the page". The rest of the page now stays exactly where it was.

## Which file do I need?

| File | Choose it if |
|---|---|
| `PaperKnife-0.5.0-setup.exe` | **Most people.** One installer for every 64-bit PC (Intel, AMD or Arm). It installs for your account only, without administrator rights, and adds PaperKnife to the Start menu and to **Open with** for PDFs. Installing it over an earlier version upgrades it in place. |
| `PaperKnife-0.5.0-x64-portable.zip` | You'd rather not install anything, on an Intel or AMD PC: unzip and run `PaperKnife.exe`. |
| `PaperKnife-0.5.0-arm64-portable.zip` | The same, on an Arm PC (for example Snapdragon). |
| `SHA256SUMS.txt` | Checksums of the files above. |

The downloads are about 65 MB larger than before: they now include LaTeX's Latin Modern and
CM-Super fonts. PaperKnife needs Windows 10 (version 1809) or later, or Windows 11. Nothing else
needs to be installed.

**This release isn't code-signed yet.** If Windows shows "Windows protected your PC", select
**More info**, then **Run anyway**. If Smart App Control is turned on, it may block PaperKnife
until releases are signed. To uninstall PaperKnife, use *Settings > Apps*.

## Known limits

PaperKnife refuses an edit rather than damage your document. In this version it can't:

- add characters that the PDF's font doesn't contain, except in LaTeX's Computer Modern, Latin
  Modern and CM-Super fonts. Even there, which characters it can add depends on how LaTeX
  encoded the font: LaTeX's default encoding has no accented letters; in PDFs made before
  mid-2021 it can add only the font's own set (CM-Super's has no accented letters the document
  doesn't use); and symbols LaTeX takes from a separate font, such as © in body text, usually
  can't be added. In encrypted LaTeX PDFs it can only delete whole lines, and in PDFs made with
  XeLaTeX or LuaLaTeX, which embed Latin Modern in another format, it can't add letters;
- keep centered text centered: the edited text starts where the old text started;
- edit some pages of encrypted PDFs: they are still edited by rewriting the whole page, which is
  refused when the page has gradients, letter spacing, print colors, small images or fonts stored
  as drawings;
- edit a line as one piece when the PDF splits it across fonts, for example the "fi" in
  "Confirmed" in PDFs saved from Chrome; each piece can be edited on its own;
- edit scripts that need text shaping (such as Hindi or Arabic), add line breaks or move text
  that follows on other lines, or edit scanned pages.

Each edit adds the page's drawing instructions to the file again: usually a few kilobytes, more on
pages with a lot of graphics. An edit that needs a copy of a font also adds the font: about 100 KB
for Latin Modern, 140 KB for CM-Super. See the
[roadmap](https://github.com/shivam098/paperknife-windows/blob/main/docs/ROADMAP.md) for what's
next.

This is an early preview: keep a backup of any document you can't afford to lose, and please
[report problems](https://github.com/shivam098/paperknife-windows/issues).
